# EventHorizon

EventHorizon is a personal Event Management App built with HTML, CSS, and Vanilla JavaScript.

The project allows users to create and manage events, track their status, and filter events based on different criteria.

## Features

* Add new events with:

  * Title
  * Date
  * Category
  * Location
* Validate event information before submission.
* Automatically classify events as:

  * Upcoming
  * Today
  * Past
* Mark events as:

  * Attended
  * Cancelled
* Delete events.
* Filter events by status and category.
* Display statistics for:

  * Total events
  * Upcoming events
  * Attended events
* Display feedback messages for successful or invalid form submissions.
* Show an empty state when no events match the selected filters.
* Responsive design for desktop and mobile screens.

## Technologies

* HTML5
* CSS3
* Vanilla JavaScript
